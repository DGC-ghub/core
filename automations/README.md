# Automações — DGC Hub

Este diretório guardará automações reutilizáveis da DGC.

Exemplos futuros:

- automação WhatsApp/API com logs;
- importação/exportação de planilhas;
- jobs de relatório;
- webhooks;
- integrações read-only com sistemas de cliente.

Regra: nenhuma automação paga deve depender de credenciais hardcoded ou fluxo frágil sem logs.
