# Systems — DGC Hub

Este diretório guardará bases e sistemas reutilizáveis da DGC.

Possíveis bases futuras:

- `base-dashboard`: React + Vite + Tailwind para dashboard simples;
- `base-crud-api`: backend CRUD com SQLite/PostgreSQL;
- `base-whatsapp-ops`: painel e logs para automações WhatsApp;
- `client-project-template`: estrutura padrão para projeto de cliente.

Regra: só criar base técnica depois de validar uso real em proposta/case.
