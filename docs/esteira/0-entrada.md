# Etapa 0 — Entrada (Briefing)

**🎯 Objetivo:** registrar o pedido com clareza **antes** de prometer qualquer coisa.

**✅ O que fazer:**
- Anotar: quem pediu, qual o problema, qual resultado espera
- Anotar: prazo desejado e orçamento (mesmo que aproximado)
- Marcar se é **cliente externo** ou **produto da casa**
- Saber **quem decide** do lado do cliente

**🤖 Como pedir pra IA** (prompt pronto pra colar):
```
Sou gestor de projeto. Recebi este pedido: [colar o pedido].
Liste as perguntas que faltam pra eu entender direito antes de propor.
Me faça essas perguntas uma de cada vez.
```

**🔍 Como conferir que não saiu lixo:**
- Consigo dizer em 1 frase o que o cliente quer?
- Sei o prazo e o orçamento?
- Sei quem decide do lado dele?

**📄 Sai daqui:** `docs/briefing.md` no repo do produto.
