# Esteira de Produção — DGC Hub

O passo a passo de como a DGC Hub tira um produto da **ideia até o ar**, guiando a IA
(Claude Code / Codex) em cada etapa — com qualidade e sem "vômito de IA".

## Como usar este manual

Começou um produto? Siga as etapas em ordem. Em cada página você acha sempre:

- 🎯 **Objetivo** — o que essa etapa entrega
- ✅ **O que fazer** — os passos
- 🤖 **Como pedir pra IA** — prompt pronto pra colar
- 🔍 **Como conferir que não saiu lixo** — checklist antes de seguir
- 📄 **Sai daqui** — o arquivo/entregável que fica pronto

## Etapas

| # | Etapa | Pra quê |
|---|-------|---------|
| 0 | [Entrada](0-entrada.md) | Registrar o pedido antes de prometer nada |
| 1 | [Descoberta](1-descoberta.md) | Fechar a regra de negócio do produto |
| 2 | [Proposta](2-proposta.md) | Escopo, preço e prazo |
| 3 | [Planejamento](3-planejamento.md) | Telas, dados, integrações, tarefas |
| 4 | [Construção com IA](4-construcao-com-ia.md) | Gerar o código guiando a IA |
| 5 | [Revisão & Testes](5-revisao-e-testes.md) | Garantir que funciona de verdade |
| 6 | [Deploy seguro](6-deploy-seguro.md) | Subir sem se expor nem quebrar |
| 7 | [Monitoramento](7-monitoramento.md) | Saber quando quebra e manter vivo |

> **Regra de ouro:** a IA faz o trabalho, mas **quem decide e confere são vocês**.
