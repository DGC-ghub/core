# Etapa 2 — Proposta

**🎯 Objetivo:** transformar a descoberta numa **proposta comercial** clara (escopo, preço, prazo).

**✅ O que fazer:**
- Definir os entregáveis por **fase** (ex: Fase 1 = login + pagamento)
- Definir preço, prazo e forma de pagamento
- Deixar explícito o que **não** está incluso
- Prever a **manutenção** (mensalidade)

**🤖 Como pedir pra IA** (prompt pronto pra colar):
```
Com base nesta regra de negócio: [colar],
escreva uma proposta comercial curta e simples:
escopo por fase, o que NÃO está incluso, prazo e estrutura de preço.
Tom profissional, sem jargão. Pra um cliente leigo entender.
```

**🔍 Como conferir que não saiu lixo:**
- O cliente leigo entende o que vai receber?
- Tem o "não incluso" escrito?
- O preço cobre a manutenção/custos depois?

**📄 Sai daqui:** `docs/proposta.md` no repo do produto.
