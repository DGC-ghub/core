# Etapa 4 — Construção com IA (Claude Code / Codex)

**🎯 Objetivo:** gerar o código **tarefa por tarefa**, guiando a IA, sem virar vômito de IA.

**✅ O que fazer:**
- Criar o repo a partir do template (**"Use this template"**)
- Abrir o Claude Code / Codex no repo
- Pedir **UMA tarefa por vez** (da lista da Etapa 3)
- Revisar e **commitar** cada tarefa antes da próxima
- O `CLAUDE.md` do repo mantém o padrão da casa

**🤖 Como pedir pra IA** (prompt por tarefa):
```
Implemente SÓ esta tarefa: [colar a tarefa].
Siga os padrões do CLAUDE.md deste repo.
Escreva o teste, rode, e me explique em 2 linhas o que fez.
Não faça nada além desta tarefa.
```

**🔍 Como conferir que não saiu lixo:**
- A IA fez **só** a tarefa pedida (não inventou recurso)?
- Tem teste e ele passou?
- Você entende o que ela fez? (se não, peça pra explicar)
- Roda sem erro?

**📄 Sai daqui:** código commitado no repo do produto.
