# Etapa 7 — Monitoramento & Manutenção

**🎯 Objetivo:** **saber quando quebra** e manter o produto vivo depois de entregue.

**✅ O que fazer:**
- Ligar um monitor de **uptime** (avisa você se o site cair)
- Ver os **erros** que os usuários enfrentam (logs / ferramenta de erro, ex: Sentry)
- Garantir **backup** dos dados (pra não perder tudo se algo der errado)
- Combinar a **manutenção** com o cliente — a mensalidade definida lá na Proposta (Etapa 2)
- Anotar melhorias e pedidos novos numa **lista** (backlog)

**🤖 Como pedir pra IA** (prompt pronto pra colar):
```
Me ajude a configurar monitoramento básico pra este app:
uptime (avisa se cair) + erros + backup dos dados.
Liste ferramentas gratuitas e o passo a passo pra ligar cada uma.
Explique pra iniciante.
```

**🔍 Como conferir que não saiu lixo:**
- Você é **avisado** se o app cair?
- Consegue **ver os erros** que os usuários enfrentam?
- Tem **backup** dos dados?
- Tem **combinado de manutenção** (mensalidade) com o cliente?
