# Etapa 7 — Monitoramento & Manutenção

**🎯 Objetivo:** **saber quando quebra** e manter o produto vivo depois de entregue.

**✅ O que fazer:**
- Ligar um monitor de **uptime** (avisa se o site cair)
- Ver os **erros** que acontecem (logs / ferramenta de erro)
- Combinar a **manutenção** com o cliente (mensalidade)
- Anotar melhorias futuras numa lista

**🤖 Como pedir pra IA** (prompt pronto pra colar):
```
Me ajude a configurar monitoramento básico pra este app:
uptime (avisa se cair) + erros. Liste ferramentas gratuitas
e o passo a passo pra ligar cada uma. Explique pra iniciante.
```

**🔍 Como conferir que não saiu lixo:**
- Você é **avisado** se o app cair?
- Consegue ver os erros que os usuários enfrentam?
- Tem contrato/combinado de manutenção com o cliente?

**📄 Sai daqui:** `docs/operacao.md` no repo do produto.
